# ☕ Tea & Coffee Sales Data Pipeline

A standalone, end-to-end data cleaning and analysis pipeline built with **pandas**,
applying every concept from Kaggle's *Pandas* micro-course to a single, realistic
retail dataset — instead of uploading raw exercise notebooks.

This project simulates two years of order-level sales for a fictional tea & coffee
retailer, then cleans, transforms, aggregates, and visualizes it to answer real
business questions: which products sell best, which regions over/under-perform
against targets, and how revenue trends month over month.

## What this project demonstrates

Each Kaggle pandas module is implemented as a concrete step in `src/pipeline.py`:

| Kaggle module | Where it's used |
|---|---|
| Creating, Reading & Writing | `load_raw_data()`, all CSV exports |
| Indexing, Selecting & Assigning | `clean_data()` — text normalization, new columns (`revenue`, `order_month`, etc.) |
| Summary Functions & Maps | `profile_data()` — `.value_counts()`, `.idxmax()`, `.map()` for order-size banding |
| Grouping & Sorting | `aggregate_sales()` — `groupby`, multi-agg, `pivot_table`, sorting |
| Data Types & Missing Values | `clean_data()` — dtype casts, per-product median imputation, duplicate/invalid-value handling |
| Renaming & Combining | `enrich_with_region_targets()` — `rename()` + `merge()` against a targets lookup table |

## Project structure

```

├── data/
│   ├── raw/                  # Raw, messy source data (generated)
│   └── processed/            # Cleaned output from the pipeline
├── src/
│   ├── generate_data.py      # Creates the realistic raw dataset
│   └── pipeline.py           # The full cleaning + analysis pipeline

│   └── test_pipeline.py      # Sanity checks on the cleaned data
├── output/

│   └── reports/                # CSV + Markdown summary reports

├── .gitignore
└── README.md
```

## How to run it

```bash
# 1. Clone your repo and enter it
git clone https://github.com/<Nathan-Warutere>/tea-coffee-sales-pipeline.git
cd tea-coffee-sales-pipeline

# 2. Install dependencies
pip install -r requirements.txt

# 3. Generate the raw dataset (only needed once / to regenerate)
python src/generate_data.py

# 4. Run the full pipeline
python src/pipeline.py

# 5. (Optional) Verify data quality
python tests/test_pipeline.py
```

After step 4, check `data/processed/tea_coffee_sales_clean.csv`,
`output/reports/`, and `output/charts/` for results.

## Sample results

- **Total revenue:** ~$109,574
- **Most popular product:** Masala Chai

## Why this approach

Rather than uploading raw Kaggle exercise notebooks, this repo is a self-contained
capstone: a realistic dataset, a reusable and logged pipeline script, automated
sanity checks, and generated reports/charts — the kind of structure a recruiter
or collaborator can clone and run in under a minute.
